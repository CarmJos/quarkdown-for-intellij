Quarkdown for IntelliJ brings the full Quarkdown language support to IntelliJ-based IDEs. In a few minutes you can start writing .qd documents with syntax highlighting, smart code completion, real-time error detection, and a live preview that refreshes as you save.

Step 1 – Install a compatible JetBrains IDE

Quarkdown for IntelliJ works in any IntelliJ-based IDE, including IntelliJ IDEA (Community or Ultimate), PyCharm, CLion, WebStorm, GoLand, and Android Studio. The plugin requires IDE version 2025.2 or later. If you do not have an IDE installed yet, download one from the JetBrains website and install it first.

Step 2 – Install the plugin

  1. Launch your IDE and open Settings/Preferences → Plugins.
  2. Switch to the Marketplace tab and search for Quarkdown.
  3. Click Install and restart the IDE when prompted.

Prefer to install from disk? Download the latest release from the GitHub Releases page, then go to Settings/Preferences → Plugins → ⚙️ → Install Plugin from Disk… and select the downloaded .zip file.

Step 3 – Install the Quarkdown command-line tool

The plugin uses the Quarkdown CLI under the hood for code completion, error checking, and the live preview. Make sure it is installed and available on your system PATH, or set the QUARKDOWN_HOME environment variable to your Quarkdown installation folder.

You do not need to configure anything manually – the plugin auto-detects your Quarkdown installation when the IDE starts. If no installation is found, the plugin settings show a clear hint with the exact command to install it, so you can get up and running in one step.

Step 4 – Configure the plugin (optional)

Open Settings/Preferences → Languages & Frameworks → Quarkdown to fine-tune the plugin to your workflow:

  • Quarkdown path – point to your Quarkdown installation manually if auto-detection does not find it. When no installation is detected, the settings page offers a one-click download of the latest Quarkdown CLI and configures it for you.
  • Compile parameters – configure command-line arguments and the output directory used when building documents.
  • Preview parameters – adjust how the live preview is generated and served, including watch mode, the browser to use, and the server port (the plugin automatically picks a free port when the configured one is occupied).
  • Color scheme – customize per-element styling for headings, code blocks, tables, and more under Editor → Color Scheme → Quarkdown.

Step 5 – Start writing Quarkdown

Create your first document via File → New → Quarkdown Document (a ready-made template is included), or simply create a file with the .qd extension and start typing. You will immediately benefit from:

  • Full syntax highlighting and real-time error detection as you type.
  • Intelligent code completion for functions, parameters, and file paths.
  • Quick documentation, go-to-definition, find-usages, and rename refactoring for references and includes.
  • A live preview panel that auto-refreshes on save, with one-click export to PDF through the built-in Quarkdown Build run configuration.

Complementary and conflicting plugins

Quarkdown for IntelliJ works side by side with the built-in Markdown plugin that ships with IntelliJ-based IDEs – both can be used in the same project without conflicts, and Quarkdown intentionally mirrors Markdown's editing conveniences (floating table bars, code folding, and more) so the experience feels familiar.

There are currently no known conflicting plugins. If you run into an incompatibility with another plugin, please report it on the issue tracker so we can look into it.
